# Manual — Mis aprobaciones

El manual de usuario con índice lateral (mismo formato que Compras, SP, etc.) está en:

- Contenido: `docs/manual-aprobaciones/contenido.php`
- Vista web: Centro de ayuda → **Mis aprobaciones y circuitos** (`route('manual_aprobaciones')`)
- Regenerar PDF/Word: `php docs/manual-aprobaciones/generar.php`

Config admin del circuito AR: **Configuración general** → Aprobaciones / Stock.
