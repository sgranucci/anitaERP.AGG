Flujo operativo simplificado

1. Abrir jornada
jornada_gastronomia		 → 2. Habilitar turno
turno_operativo_gastronomia		 → 3. Cuentas
cuenta_gastronomia + líneas		 → 4. Facturar
venta + venta_gastronomia_emision		 → 5. Cierre / rendición
rendicion_gastronomia_caja

Grupos funcionales

Maestros / layout: ubicaciones, mesas, mozos, descuentos, turnos horarios, áreas comanda
Configuración: terminal PV, tótems Waitry, config contable cierre jornada
Jornada: día operativo, turnos por PC, cierres parciales, cierre totem, snapshot contable
Operación: cuenta (mesa/libre), líneas, emisión venta, cola Waitry
Canjes: fidelidad Wigos, premio cupón, ticket tarjeta CTG
Caja: rendición Anita, movimientos por cuenta de caja, secuencia por empresa
